Нівелювання.тах: проєкт збірки Android-застосунку (.apk)

Що тут:
- www/index.html: сама програма (один файл, без бібліотек).
- android-res/: іконки (тахіометр з лазером) у всіх розмірах Android.
- keystore/debug.keystore: постійний тестовий ключ підпису. Завдяки йому нову версію можна встановлювати ПОВЕРХ старої, і записи в програмі не зникають. Не видаляйте його з проєкту.
- .github/workflows/build.yml: сценарій, за яким GitHub сам збирає .apk (Node 22, Java 21, Capacitor 8.4.2, версії зафіксовано).
- capacitor.config.json, package.json: налаштування застосунку.

Як отримати .apk: завантажити всі ці файли в репозиторій GitHub, вкладка Actions, запуск Build APK, готовий файл у розділі Artifacts (nivelyuvannya-tah-apk).

Нова версія програми: замінити в репозиторії лише файл www/index.html. Збірка запуститься сама, а номер версії зросте автоматично.

Перед видаленням застосунку з телефона зробіть Експорт кожної сторінки: видалення стирає всі записи.
